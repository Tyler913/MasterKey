# MasterKey application icon

AI-generated artwork, packaged into macOS icon sizes with `sips` and `iconutil`.

- Original artwork: `Resources/AppIcon.png`
- Application icon: `Resources/AppIcon.icns`
- Integration: application bundle, Finder icon, Dock icon, and settings header. The menu bar uses a native monochrome mouse symbol with an MK label.

Final generation prompt:

> Use case: logo-brand. Asset type: final macOS application icon for MasterKey, a lightweight mouse-button-to-voice-shortcut utility. Create one original polished icon, square 1024 × 1024 PNG. Preserve the application's existing blue/indigo identity. A clean, substantial pearl-white computer mouse symbol with one clearly defined side button; integrate three short rounded voice-wave bars beside the side button into a single coherent mark. Modern restrained macOS utility icon, soft sculpted depth and precise edges, subtle studio highlights, immediately legible at 32 pixels. Center the mark on an indigo-to-blue macOS-style rounded-square tile, occupying about 86% of the canvas, with balanced breathing room. Genuinely transparent pixels outside the tile, not a checkerboard or solid background. Front-facing orthographic icon, no perspective mockup, no scene, no border frame, no text, no letters, no watermark, no existing brand logos. Deliver a single finished icon, not a grid of options.

The saved transparent master is 1254 × 1254 pixels; macOS icon representations are resized from this source.
